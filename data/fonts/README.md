# Pixel Operator 8

This is the exact `PixelOperator8.ttf` face used by Warforge's current GUI.
It is the unchanged 2018.10.04-1 release by Jayvee Enaguas (HarvettFox96).

The game bakes this face at eight source pixels, using monochrome bitmap
rasterization and point filtering. Text scales only by whole pixel multiples,
with an eight-source-pixel line height. The included Latin characters preserve
the font's original case and glyph advances.

The original copyright notice and CC0 1.0 license accompany the font. Source:
[Pixel Operator on DaFont](https://www.dafont.com/pixel-operator.font).
